# XorV — загрузки

Это официальный репозиторий APK-релизов Android-приложения XorV.

XorV помогает спокойно организовать личные задачи и текстовые заметки.
Приложение работает по принципу local-first: основные функции доступны без
Интернета, а локальная база остаётся главным источником данных.

## Текущая версия

**XorV 1.0.0**

- имя пакета: `app.xorv`;
- минимальная версия системы: Android 7.0 (API 24);
- платформа: Android;
- архитектура: local-first.

Скачать подписанный APK:
[XorV-1.0.0.apk](https://github.com/robotovnet/xorv-releases/releases/latest/download/XorV-1.0.0.apk).

## Возможности версии 1.0

- личные задачи с датами, ручным порядком и списком выполненных;
- обычные текстовые заметки;
- отдельный локальный поиск по задачам и заметкам;
- светлая и тёмная темы;
- резервные копии и восстановление через Яндекс Диск;
- синхронизация личных данных между несколькими устройствами;
- полный локальный ZIP-экспорт Tasks и Notes.

Для локальной работы подключение Яндекс Диска не требуется.

## Установка APK

1. Откройте страницу Releases и выберите последнюю стабильную версию.
2. Скачайте файл вида `XorV-1.0.0.apk`.
3. Сверьте SHA-256 файла со значением в описании релиза.
4. Разрешите Android установку приложений из используемого браузера или
   файлового менеджера.
5. Откройте APK и подтвердите установку.

Android может предупреждать об установке приложения не из магазина. Загружайте
APK только из Releases этого репозитория.

Для обновления установленного приложения новый APK должен быть подписан тем же
release-ключом. Не удаляйте приложение перед обновлением, если хотите сохранить
локальные данные.

## Данные и безопасность

- XorV не содержит рекламы и не продаёт пользовательские данные;
- локальная работа не требует учётной записи XorV;
- экспорт не содержит OAuth-токены и внутреннее состояние синхронизации;
- версия 1.0 не выполняет собственное сквозное шифрование содержимого.

Не храните в приложении пароли и другие секреты.

## Что не входит в версию 1.0

- семейные пространства и совместные заметки;
- уведомления, виджеты и вложения;
- AI-функции;
- импорт ZIP-экспорта;
- Google Drive;
- версии для iOS, web и desktop.
